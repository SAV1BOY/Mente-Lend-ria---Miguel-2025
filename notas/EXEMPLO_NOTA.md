# Exemplo de Nota - Mente Lendária

Este é um exemplo de como as notas devem ser formatadas neste repositório.

## 📋 Estrutura

Cada nota deve conter:

1. **Frontmatter YAML** (metadados no topo)
2. **Título principal** (H1)
3. **Conteúdo** organizado em seções
4. **Links** para outras notas (quando aplicável)
5. **Referências** à fonte original

## 🔗 Links Internos

Para referenciar outras notas, use o formato WikiLink:
- `[[Nome da Nota]]`
- `[[Nome da Nota|Texto Alternativo]]`

## 📝 Formatação

Você pode usar toda a sintaxe Markdown:

### Listas
- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2

### Listas Numeradas
1. Primeiro passo
2. Segundo passo
3. Terceiro passo

### Citações
> "Este é um exemplo de citação importante."
> — Autor da Citação

### Código
```python
def exemplo():
    print("Código de exemplo")
```

### Tabelas
| Coluna 1 | Coluna 2 | Coluna 3 |
|----------|----------|----------|
| Dado 1   | Dado 2   | Dado 3   |
| Dado 4   | Dado 5   | Dado 6   |

## 🎯 Tags e Categorização

Use tags no frontmatter para organizar:
```yaml
tags: [categoria1, categoria2, tema]
```
